# CoralGuard

Simulationsbasierte Web-Anwendung zur Förderung von Systemkompetenz
am Beispiel der Korallenbleiche im Biologieunterricht der
Sekundarstufe I. Entstanden im Rahmen einer Bachelorarbeit.

## Nutzung
Einstiegsseite ist index.html. Die Datei kann direkt im Browser
geöffnet werden; ein Webserver ist nicht erforderlich.

## Projektstruktur
- index.html   – vollständige Anwendung (Auszeichnung, Gestaltung, Logik)
- p5.min.js    – Rendering-Bibliothek p5.js 1.9.0
- fonts/       – lokal eingebundene Schriftdateien
- licenses/    – Lizenztexte der Fremdbestandteile

11. August 2026 mit dem Sprachmodell Claude Opus 5 (Anbieter:
Anthropic) über die Entwicklungsumgebung Claude for Windows
erzeugt. Die Datei index.html ist vollständig modellgeneriert;

Überarbeitungen erfolgten innerhalb der Sitzung auf Grundlage
weiterer Anweisungen, fachlicher Vorgaben und Testrückmeldungen.

die eingebundenen Schriftdateien; beide wurden beschafft und im

zwischen rasch einsetzender Bleiche und langsamer Erholung nicht
zugunsten der Spielbarkeit zu verändern. Die Prüfung der
