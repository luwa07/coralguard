# Medien- und Schriftnachweise

Die Anwendung bindet keine Bilddateien ein. Sämtliche Grafiken,
Symbole und Figuren werden zur Laufzeit im Programm gezeichnet
und sind eigene Werke.

Als Fremdmaterial sind ausschließlich die folgenden Schriftarten
enthalten:

- Urheber: Copyright © 2017 IBM Corp., with Reserved Font Name "Plex"
- Lizenz: SIL Open Font License, Version 1.1

- Verwendung: Messwerte, Zahlenangaben, Skalen- und Diagrammbeschriftungen
